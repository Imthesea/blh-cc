## Python → TS 适配要点

| # | Python 蓝本 | TS 适配 | 理由 |
|---|---|---|---|
| 1 | `threading.Thread` daemon 跑 subagent/teammate | subagent 同步嵌套 loop;teammate 用 `void runtime.run()` fire-and-forget async + 轮询 | Node 无线程;事件循环天然异步 |
| 2 | `threading.Condition` 收件箱唤醒 | 无锁文件收件箱;`waitForMessages` 用 20ms `setTimeout` 轮询 | Node 单线程天然互斥 |
| 3 | `subprocess.run(capture_output=True, timeout=30)` 执行 git | `spawnSync("git", args, { cwd, encoding, timeout })` | 同步 git 操作 |
| 4 | `os.tmpdir()` 短路径(8.3)与 git 长路径不一致 | worktree 注册表按 branch 索引 + 仓库根校验改用 `rev-parse --show-cdup` | Windows 8.3 短路径 |

| 8 | 协议 metadata 用 snake_case(`request_id`、`approve`) | 逐字保留 snake_case | 协议匹配逐字一致 |
| 9 | `f"req_{random.randint(0,999999):06d}"` 生成 request id | `req_${Math.floor(Math.random()*1000000).toString().padStart(6,"0")}` | 逐字等价 |

**目标:** git worktree 纯操作:名称校验/路径解析/`runGit`/`registeredWorktree`/`taskCwd`/`createWorktree`/`removeWorktree`。

**文件:** `src/agents/worktree.ts`(新建)、`test/agents/worktree.test.ts`(新建)

- `taskCwd returns workdir for no worktree`
- `createWorktree binds task and registers`
- `createWorktree rejects non-root working directory`

**实现要点:**
- `runGit` 用 `spawnSync`;空输出归一为 `"(no output)"`。
- Windows 短路径适配:`registeredWorktrees` 按 branch 为键索引(而非路径),仓库根校验用 `rev-parse --show-cdup` 返回 `"(no output)"`。

```ts
export function runGit(args: string[], cwd: string): [boolean, string] {
  const result = spawnSync("git", args, { cwd, encoding: "utf8", timeout: 30000 });
  const output = ((result.stdout ?? "") + (result.stderr ?? "")).trim();
  if (result.error) return [false, `${result.error.name}: ${result.error.message}`];
  return [result.status === 0, output.slice(0, 5000) || "(no output)"];
}
```
